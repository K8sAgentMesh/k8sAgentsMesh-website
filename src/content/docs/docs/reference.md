The reference appendix collects the schemas and contracts that do not belong
to a single task-oriented guide.

## Planned contents

- **Lifecycle event schema** — the event envelope emitted across the agent
  lifecycle (source of truth: `mesh/EVENTS.md` in the product repo).
- **A2A wire types** — `Task` / `Event` / `Status` / `AgentCard` /
  `ModelRoute` (source of truth: `a2a/` package).
- **Gateway conditions** — the real gateway condition reasons (e.g. no idle
  process, process busy).
- **Glossary** — mesh, pool, route, runtime adapter, standing band.

## Where this content lands

These pages are written in phase P2 of the website plan. Until then, see the
product repo's `mesh/EVENTS.md` and `a2a/` package.
