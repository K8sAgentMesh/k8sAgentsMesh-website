*2026-10-17*

**v0.1.0** is the first tagged release of
[K8sAgentMesh](https://github.com/K8sAgentMesh/K8sAgentMesh): the complete P3
extraction, lifted from the proven seam in k8squad and pinned by host #1.

## What's in it

- `mesh` — RuntimeAdapter 7-op contract (Spawn / Register / Route / Hibernate
  / Wake / Stop / Recreate), per-pod Gateway process manager, router,
  lifecycle state machine, child-process substrate, runtime adapters;
  supervisor seams (`Registry`, `Ingress`, `Sweeper`, `SupervisorHealth`);
  `SchedulingPolicy` seam + target-N scheduler loop; `LifecycleObserver`
  event contract.
- `a2a` — A2A wire types (Task / Event / Status / AgentCard / ModelRoute).
- `apis/mesh/v1alpha1` — Tier-A CRD contracts: `MeshPool`, `MeshRoute`,
  `MeshTelemetry` (types + YAML, no controller).

## Guarantees the release carries

- **Extraction-clean**: no module package imports the host; the guard runs in
  CI, including on CRD shapes.
- **Host-agnostic**: host #1 (k8squad) pins the module with its RolePool
  scheduling plugged in as `SchedulingPolicy` #1 — full suite green.
- **Lifted, not rewritten**: every line of mechanism was proven in a running
  platform before it moved.

```bash
go get github.com/K8sAgentMesh/K8sAgentMesh@v0.1.0
```
